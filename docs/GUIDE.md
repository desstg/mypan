# MyPan 使用说明

> 把分散在多个网盘里的影视资源，收成一条自动化的影音工作流。

MyPan 是一个自托管的网盘聚合面板。它把 115、夸克、百度、天翼等网盘挂到同一个界面里浏览和管理，并且围绕「影视库」这件事做了一整套自动化：**扫描网盘 → 生成 STRM → 刮削海报和 NFO → 整理目录 → 通知 Emby/Jellyfin 刷新**。生成的 STRM 文件可以被 Emby、Jellyfin、飞牛影视直接播放，播放时走网盘直链，不占服务器硬盘。

程序是一个**单二进制 + 内嵌网页界面**，全部配置和数据落在一个 SQLite 文件里，用 Docker 部署。

## 一、功能详解

### 1. 多网盘聚合

一个界面管理所有网盘账号，支持多账号并存、切换、启用/禁用、设置默认账号。

| 网盘 | 代码标识 | 登录方式 |
|---|---|---|
| 115 网盘（Open） | `115_open` | OAuth / Token |
| 123 云盘（Open） | `123_open` | OAuth / Token |
| 百度网盘（Open） | `baidu_open` | OAuth / Token |
| 天翼云盘 | `189_cloud` | 扫码 / Cookie / Token |
| 移动云盘 | `139_cloud` | 扫码 / Token |
| 光鸭云盘 | `guangya` | 扫码 / Token |
| 夸克网盘 | `quark` | 扫码 / Cookie |
| OneDrive | `onedrive` | OAuth |
| OpenList | `openlist` | Token |
| WebDAV | `webdav` | 地址 + 账号密码 |
| 本机存储 | `localfs` | 无需登录（直接读服务器本地路径） |

> **扫码登录**支持天翼云盘、移动云盘、光鸭云盘、夸克、**115**；其余走 OAuth 或手动填 Token。
>
> 115 的扫码登录有一个**必须先知道的坑**：115 每个客户端类型只允许一个活跃会话，以类型 X 登录会把已有的 X 会话登出。所以扫码弹窗里有个「登录类型」下拉，**默认 `alipaymini`（支付宝小程序）**——你几乎不会在支付宝里登录 115，所以那个会话实质长期有效。**别选「网页版」**：它会踢掉你浏览器里的 115 登录，也最容易触发风控。

**各网盘能力并不一致**，下面这些差异会直接影响你能用哪些功能：

| 能力 | 支持情况 |
|---|---|
| **能接收秒传**（作为传输目标） | 仅 `123_open`、`guangya`、`189_cloud` |
| **秒传预检**（先探测再传） | 仅 `189_cloud` |
| **能提供秒传哈希**（作为传输源） | `baidu_open`、`guangya`、`189_cloud` |
| **网盘离线下载** | `115_open`（最全，含磁力、ed2k 和种子）、`guangya`（批量 URL，无 ed2k）、`123_open`（单条 URL，且不支持删除离线任务） |
| **分享转存**（把别人的分享存进自己网盘） | 仅 `115_open`，且**该账号需额外配置网页 Cookie** —— 见 [TG 影片订阅](#14-tg-影片订阅) |
| **302 直链** | 除夸克外均支持；**夸克只支持本机代理**，不支持 302 |
| 全量递归列目录（STRM 扫描加速） | 仅 `115_open` |

> 百度网盘能当秒传的**源**（可以吐出 md5），但当不了**目标**（收不了秒传）。所以「百度 → 115」这种组合不会触发秒传，会走普通上传，这是正常的。

### 2. 文件管理

- **浏览**：列表 / 网格两种视图，面包屑导航，会记住上次浏览的位置。
- **操作**：新建文件夹、重命名、移动、复制、删除、下载。
- **上传**：支持上传文件、上传整个文件夹，有独立的传输任务面板可以暂停 / 恢复 / 批量删除。
- **收藏夹**：把常用目录收藏起来，支持重命名、排序、拖拽整理。
- **命名对齐**：批量规范化影视文件名，**先预览再应用**。
- **拖拽移动**：直接把文件拖到文件夹上完成移动（悬停约 0.6 秒才会触发，避免误操作）。
- **一键生成 STRM**：在任意目录直接为当前目录生成 STRM，不用先去建任务。

### 3. 在线预览

不用下载就能看。共 9 类预览：

| 类型 | 支持格式 | 说明 |
|---|---|---|
| **视频** | mp4 / mkv / avi / mov / flv / wmv / webm / ts / m3u8 / rmvb | HLS（m3u8）走 hls.js，FLV/TS 走 mpegts.js |
| **音频** | mp3 / flac / wav / aac / ogg / opus / m4a / ape / wma | 自动播放同目录音频，可上/下一首 |
| **图片** | jpg / png / gif / webp / bmp / svg / avif / **heic / heif** | HEIC/HEIF 在前端解码，无需转码 |
| **PDF** | pdf | 缩放、旋转、**全文搜索**、支持**加密 PDF** |
| **Word** | **仅 .docx** | `.doc` 会提示下载 |
| **表格** | xls / xlsx / csv / ods | 多 sheet、分页、合并单元格、CSV 编码自动识别 |
| **PPT** | **仅 .pptx** | `.ppt` 会提示下载 |
| **压缩包** | **仅 .zip / .cbz** | 用 HTTP Range 读，**不落盘解压**就能浏览内部、支持加密包 |
| **文本** | txt / md / rtf / log / strm / nfo / srt / ass / lrc / xml / yml / json / 各类代码 | Markdown 带目录渲染；RTF 渲染且屏蔽外部资源 |

**视频预览**还额外支持：

- **字幕**：SRT / VTT / **SUP（图形字幕）**，按文件名自动匹配中/英/日/韩多语言
- 剧集连播（自动跳下一集）、0.5–2 倍速、全屏
- 快捷键：`←/→` 快退快进 10 秒、`↑/↓` 音量、`空格` 播放暂停、`N/P` 切换剧集、`M` 静音

### 4. STRM 直连播放

这是 MyPan 的核心。它扫描网盘目录，为每个视频文件生成一个 `.strm` 文本文件（内容是一行播放地址），Emby / Jellyfin / 飞牛影视扫描到这个文件后，播放时请求会打到 MyPan，由 MyPan 换取网盘直链并 **302 跳转**过去。

好处是：**媒体服务器不占用本地硬盘，也不消耗服务器带宽**（直链模式下流量直接从网盘到播放器）。

STRM 任务的配置项：

- **扫描模式**：增量补缺（只补新增）/ 增量更新 / 全量同步
- **调度方式**：时间窗口（在指定时段内跑）/ 手动
- **分组目录 + 输出目录**：生成的 .strm 落到哪里
- **文件扩展名**：决定哪些格式生成 STRM
- **排除目录 / 排除文件名关键字**
- **分支**：一个任务下可以建多条「入口分支」和「监控分支」，监控分支可设保留天数，适合临时追更某个剧集
- **元数据同步**、**冲突策略**
- **媒体类型**：`tmdb影片`（默认，行为与以前完全一样）或 `番号影片`

选「番号影片」并且开了「同步元数据」时，任务会把番号推送时写在视频同层的
**侧车 JSON**（`<番号>[-U|-C|-UC][-4K].json`）一并同步到本地，再读**本地那份**生成
Emby 认的元数据，全部落在 `.strm` 同层：

| 文件 | 是什么 | 怎么来的 |
|---|---|---|
| `<主干>.nfo` | 影片信息（番号 / 演员 / 片商 / 系列 / 标签 / 评分 / 剧情） | 侧车里的字段 |
| `thumb.jpg` | 缩略图（横版大图） | 侧车的封面原图 |
| `poster.jpg` | 海报 | 从 `thumb.jpg` 按 2:3 裁；**有码取右侧**，其余按人脸检测 |
| `fanart.jpg` | 背景横幅 | `thumb.jpg` 的一份副本 |
| `extrafanart/fanartN.jpg` | 剧照 | 侧车里的全部剧照 |

生成哪些项由「STRM 设置 → 元数据同步 → **番号元数据**」那六个复选框决定（默认全选，
其中「字幕」暂时是占位）。老片子不会自动回头补，想批量回填就在文件浏览器里对那个目录
点「**生成当前目录 STRM**」。

配套工具：

- **播放地址替换**：网盘直链的域名变了，批量改掉已有 .strm 里的地址
- **账号引用修复**：账号重建后修复 .strm 里失效的账号引用
- **115 目录树清单增强**：115 独有的全量列目录加速

### 5. STRM 刮削

扫描 STRM 任务产出的目录，自动匹配 TMDB，写出 **NFO**（`movie.nfo` / `tvshow.nfo` / 分季分集 NFO）和 **海报图**，让 Emby / Jellyfin 直接就有海报墙。

- 界面上是一个**海报墙**，可以直接看到哪些匹配上了、哪些没匹配上
- 单条操作：**重新匹配**（换 TMDB ID）、**重新刮削**（同 ID 重跑）、**标记为正常**（清掉错误匹配）
- 写入模式：只补缺失 / 全部覆盖
- 支持电视剧的**连载状态跟踪**（已完结 / 连载中）
- 可以限定刮削范围（排除某些目录）

### 6. 目录整理

TMDB 识别 → **生成计划** → **预览** → **应用**。识别出的影片会被改名并移动到目标目录，命名规则可以对齐媒体标签（分辨率 / 编码 / 音轨 / 声道）。

**计划在应用前完全可编辑** —— 可以逐条修改、删除，也可以批量删掉误识别的，确认无误再执行。

提供两套互相独立的识别方案：

- **TMDB 方案**：适合电影和电视剧
- **番号方案**：基于规则匹配，带小文件删除、空目录清理、扫描目录限制

还有：

- **分类整理**：自定义分类模板
- **AI 辅助识别**：对低置信度的匹配用 AI 再判一次（默认接 DeepSeek 兼容接口，需自行配置）

### 7. 自动联动

把上面这些串成流水线。规则 = **触发器** + 一串**动作**。

**触发器**：每天定时 / 每隔 N 小时 / Webhook / 离线下载完成

**动作**（按顺序执行）：延迟 → 刷新目录缓存 → 目录整理 → 生成 STRM → 刮削 → 通知 Emby 刷新 → 补全 Emby 媒体信息

每个动作可以设**执行条件**：总是执行 / 上一步成功才执行 / 上一步失败才执行。目录整理还能设风险阈值（匹配风险超过阈值就停下等你人工确认）。

有运行记录可查。

**Webhook** 走 `/api/open/automation/events`，需要用 API 秘钥鉴权，可以按事件和路径前缀匹配。

### 8. 跨盘传输

把文件从一个网盘搬到另一个网盘，两种模式：

- **跨盘秒传**：先扫描源目录算出哈希，再**探测**目标盘能不能秒传，能就秒传（几乎是瞬间完成），**不能就自动降级为「中转上传」**（先下载到服务器再上传）。
- **跨盘普传**：老老实实下载再上传，适合目标盘不支持秒传的情况。

冲突策略可选：跳过 / 重命名 / 覆盖。

> 因为秒传只在部分网盘生效，**「115 → 115」这种组合不会触发秒传**。参见 [第 1 节的能力表](#1-多网盘聚合)。

### 9. 挂载：WebDAV 与 FUSE

把网盘挂出去给自己用。注意：这是**挂载**，不是生成公开分享链接 —— MyPan 没有分享链接功能。

**WebDAV**

开启后通过 `/dav/<账号>/...` 访问，用管理员账号密码做 Basic 认证。支持列目录、下载、上传、重命名、移动、删除、新建目录。目录列表有缓存可加速。

**FUSE 本地挂载**

把网盘目录挂成本机文件系统路径，让其他程序（比如 Emby、qBittorrent、各种播放器）能像读本地文件一样读网盘。

- 支持**读写** —— 往挂载点里写的文件会被暂存，然后自动转为上传任务传到网盘
- 每个挂载点可单独设 UID / GID、开机自动挂载
- 账号重新授权后会自动重新挂载
- **FUSE 读缓存**：把读过的数据块缓存在本地磁盘，明显加快重复读取。缓存大小、保留天数、淘汰策略（LRU / 大文件优先）都可配，建议把缓存目录放到更快的盘上

> FUSE 需要容器有 `privileged: true`、挂载 `/dev/fuse`、并且 `pid: "host"`。官方镜像是带 FUSE 支持编译的。

### 10. 离线下载

有两条路：

**网盘离线下载** —— 把链接或种子交给网盘，让网盘自己去下（不占服务器带宽）。支持情况见[能力表](#1-多网盘聚合)：115 最全（含磁力/种子/ed2k），光鸭支持批量 URL（无 ed2k），123 只支持单条 URL 且不能删除任务。链接类型是按 **scheme**（`magnet:` / `ed2k:` / `http(s):`）与网盘声明支持的能力匹配的，具体某个账号支持哪些在「TG 订阅」的推送里会自动判定。

**内置下载器** —— MyPan 自己下载，支持：

- **HTTP / HTTPS**：支持断点续传
- **磁力 / BitTorrent**：基于 DHT，TCP/uTP 双协议

⚠️ 内置下载器**不支持 ed2k**。ed2k 只能走 115 网盘的原生离线下载。

内置 BT 的**默认监听端口是 42069**（TCP + UDP），所以 Docker 里 `EXPOSE 42069/tcp 42069/udp` 就是它。用 host 网络时无需额外映射；用 bridge 网络记得把 TCP 和 UDP 都映射出去，否则 DHT 拿不到节点、速度会很差。

下载完成后会自动交接给上传任务传到目标网盘。可以设临时目录、全局限速、BT 端口。

### 11. 缓存保持

网盘列目录是有成本的。缓存保持任务会在设定的时间窗口内主动遍历指定目录，把**目录和元数据缓存焐热**，这样你点进去浏览时是秒开，而不是转圈等网盘返回。

按账号设置扫描范围，支持立即运行、强制停止。它和 STRM / 目录整理任务在**同一个账号上互斥**，不会同时跑。

### 12. 媒体端反代

给 Emby / Jellyfin / 飞牛影视用的代理层，把媒体服务器的 STRM 播放请求转成网盘 **302 直链**。

这样做的意义是降低直链直接暴露的风险，同时方便统一管理播放地址。

- **Emby 反代**：Emby/Jellyfin 配置、媒体库列表、触发刷新、补全媒体信息
- **飞牛影视反代**：飞牛配置、端口、STRM 路径映射、直链客户端管理

### 13. 任务、日志、备份、通知

**任务系统**：STRM、缓存保持、目录整理、自动联动、上传、离线下载全部落库，重启后自动恢复（会把上次异常中断的「运行中」状态纠正回来）。统一都有启用/禁用、立即运行、强制停止、进度查看。

**日志**：分级（debug/info/warn/error），按天落文件在 `data/log`。可设日志级别和保留天数，启动时自动清理过期日志。界面上可以查看、统计、确认错误、一键清理。

**备份**：生成 `.lpb` 备份文件（可选密码加密），支持完整备份和仅设置备份。恢复是**在下次启动时应用**的，失败会回滚。注意备份加密用的是 `MyPan_SECRET_KEY`。

**通知与公告**：站内通知中心（带未读数）+ 后台公告弹窗。

### 14. TG 影片订阅

把 Telegram 公开频道里的资源消息抓下来，按已订阅的影片做匹配，命中的自动推送到网盘。

**取消息方式**：抓 Telegram 的**公开网页预览**（`t.me/s/<频道>`）。

这意味着**不需要 Bot，也不需要把任何账号、机器人拉进频道** —— 别人的频道也能订阅。代价是下面这几条限制，添加频道前请先看清楚。

**首次启动会自动添加几个默认频道**：实测筛出来的、抽得出来而且**投得出去**的公开频道（`Channel_Shares_115`、`gimy115iso`、`QukanMovie`、`vip115hot`），启动时会自动校验并入库，打开「TG 频道」就在那张表里 —— 它们与你手填的频道完全等同，可以编辑、停用、删除。

- **只添加这一次**。你删掉某个默认频道后，它不会被下次启动塞回来。
- 自动添加需要能访问 t.me：**新装实例如果还没配代理，这次会一条都加不上**（启动日志里会写）。配好代理后重启即可；也可以在「TG 频道」列表里对剩下那几条点「补加」。
- 不想用它们中的某一个？直接删掉即可，不会影响其它功能。

**能抓哪些资源**：

| 类型 | 抽取 | 投递 |
|---|---|---|
| 磁力链接（magnet） | ✅ | ✅ 网盘原生离线，不支持时自动降级到内置下载器 |
| ed2k | ✅ | ⚠️ **只有 115 网盘**能投（内置下载器与其它网盘都不吃 ed2k） |
| http/https 视频直链 | ✅ | ✅ 网盘原生离线或内置下载器 |
| 115 分享链（`115.com/s/xxx`） | ✅ | ✅ 自动转存 —— **需要该 115 账号配置「网页 Cookie」**，见下 |
| 夸克分享链（`pan.quark.cn/s/xxx`） | ✅ | ❌ 目前只能识别 |

**115 分享链的自动转存**：115 的分享转存只有**网页版接口**能做（开放平台的 API 里没有这个动作），所以要在 115 账号的配置里额外粘一份**浏览器 Cookie**：

**取 Cookie 有两条路**：

- **推荐：扫码**。编辑 115 账号 → 点「扫码获取授权」→ 用手机 115 生活 App 扫码确认，Cookie 自动填进表单。登录类型默认「支付宝小程序」，不用改（见[第 1 节](#1-多网盘聚合)里的互踢说明）。
- **手动**：浏览器登录 `115.com`，开发者工具 → Network → 任意请求 → 复制请求头里的 `Cookie` 整段，粘进 115 账号的「网页 Cookie」一栏。

配好之后，识别到的 115 分享链会**整份转存**到订阅的目标目录（走的是「片名 (年份)」子目录，与磁力推送一致）。几点要注意：

- Cookie 会过期。失效后接口会明确提示「Cookie 已失效」，重新粘一份即可 —— **不会**自动重试到把账号撞进风控。
- 分享链是**整份**转存的：分享里除了你要的那一集，别的文件也会一起进网盘。对整季包是好事，对「一个分享里塞了十几部不相干的片」是浪费空间。
- 转存**不产生离线下载任务**，所以「下载管理」里看不到它；订阅进度（剧集入库、自动收尾）照常回写。
- 某些出口 IP 会被 115 直接拒绝（常见于香港机房，返回 403）或触发风控（405）。遇到时报错会说清是哪一种，重试不会好 —— 前者要换出口，后者要等解封。

抓不到但投不出去的类型会以 **「已识别，暂不支持投递」** 出现在匹配历史里 —— 它**不会**进重试队列，也不会占推送额度。同理，如果目标网盘收不了这个协议（例如把 ed2k 推给 123 账号），记录也会是「暂不支持投递」并写明原因，而不是反复失败重试。没配网页 Cookie 的 115 账号收到分享链时也是这一档，原因里会直接写明缺 Cookie。

还有一类是 **「推送失败（不会重试）」**：这次没成，而且重试也不会好（提取码错误、分享已失效/被删、目标目录对不上、同一个分享已接收过）。这类同样不进重试队列——对 115 反复试反而可能触发风控。修好问题后可以在匹配历史里手动再推一次。

**已知限制**：

1. **只支持公开频道。** 私有频道和邀请链接（`t.me/+xxx`）没有网页预览，无法订阅；填数字 ID 也不行（从数字 ID 反解用户名需要用户账号会话）。频道地址填 `@用户名` 或 `https://t.me/xxx`。
2. **下载地址藏在机器人后面的频道抓不到内容。** 有些频道正文里的「下载」「点击跳转」按钮指向 `t.me/xxx_bot`，实际链接要点进去私聊机器人才拿得到 —— 网页预览只能看到一个跳转按钮。
3. **用「点击复制」按钮发资源的频道抓不到内容。** Telegram 的网页预览不渲染 `copy_text` 按钮，只渲染普通链接按钮和正文里的链接。
4. **正文链接指向第三方中转站的频道抓不到内容**（例如全部指向 `re0.me` 这类站点）。
5. **每页固定 20 条。** 回填深度由「首次订阅回填页数」决定（默认 1 页）。停机太久导致积压超过 200 条时会截断并写进频道状态提示。
6. **订阅之前发过的帖子，增量抓取看不到。** 这是一条硬限制：订阅时只回填 1 页，所以一部已经播到第 10 集的剧，你订阅时前 9 集抓不到。**用「搜历史帖」补** —— 在订阅详情里点那个按钮，它会去频道内搜索（`t.me/s/<频道>?q=<片名>`）翻旧账，关键词用订阅的片名与别名自动拼（最多 3 个）。搜到的会以「待确认」进匹配历史，你确认后再点「立即推送」。
   - 它**只手动触发、只落库不推送**：翻出来的旧资源不该被自动推走。想推要自己点一下。
   - 每条订阅 × 每个关键词都是一次真实请求，频道多时会慢（几秒到几十秒），也可能碰上 t.me 限流 —— 结果里会写明失败了几次，稍后重试即可。
   - 搜过的不会重复落库，可以放心反复点。
7. **国内直连 t.me 通常不通**，需要在「系统设置 → 其他设置 → 网络代理」里配置代理（这个代理是全局的，TMDB 也共用同一份）。
8. **频道改名后要手动更新。** 数字 ID 仍然记录着（用来识别改名和用户名被回收），但抓取靠的是用户名 —— 频道改名后校验会报错，按提示填新地址即可。旧版按数字 ID 添加的频道需要补填公开地址，频道列表上会有提示。

**加频道前先体检**：添加/测试频道时会真实抓一次最近一页，报告抓住的各类资源数量（如「磁力 0 · ed2k 1 · 115 分享 15 · 直链 0」），并针对上面第 2–4 条给出**具体是哪种**原因的结论。看到「帖子数一直在涨、产出一直是 0」时，先点「测试」看结论，再决定换不换频道。报告里识别到 115 分享链时也会提示「自动转存需要账号配网页 Cookie」——体检是按频道做的，判断不了你的账号配没配，只能把前提讲清楚。

**排障**：「抓取设置 → 测试连接」会真实抓一次 Telegram 官方频道，一次验证网络、代理与页面结构三件事。

## 二、部署

### 环境要求

- 一台能跑 Docker 的机器（NAS、小主机、VPS 都行）
- **如果要使用 FUSE 挂载**：宿主机需要 `/dev/fuse`，容器需要 `privileged: true` 和 `pid: "host"`
- 不需要额外装数据库，SQLite 是内嵌的
- 镜像基于 `scratch`，里面只有一个静态二进制和一份根证书，没有任何系统工具

### 方式一：Docker Compose（推荐）

新建一个目录，比如 `/volume1/docker/MyPan`，在里面建 `docker-compose.yml`：

```yaml
services:
  MyPan:
    image: desstg/mypan:latest
    container_name: MyPan
    restart: unless-stopped
    ports:
      - "5211:5211"
      # 内置磁力的 TCP/uTP/DHT 监听端口；在后台改过端口的话这里要同步改
      - "42069:42069/tcp"
      - "42069:42069/udp"
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - ./data:/app/data
      - ./strm:/app/strm
      - ./mounts:/app/mounts:shared

      # 可选：把 FUSE 读缓存单独放到更快的盘上
      # - ./fuse_read_cache:/app/data/fuse_read_cache
    devices:
      - /dev/fuse:/dev/fuse
    pid: "host"
    privileged: true
```

然后：

```bash
docker compose up -d
```

打开 `http://你的IP:5211`。

> **`mounts` 后面的 `:shared` 不能省。** FUSE 在容器内挂载后需要把挂载点传播到宿主机，去掉 `:shared` 挂载会失效。
>
> **`privileged: true` + `/dev/fuse` + `pid: "host"` 三件套也不能省**，少任何一个 FUSE 都用不了。如果你确定不用 FUSE 挂载，这三项可以去掉。

### 方式二：host 网络（省掉端口映射）

NAS 上常用，尤其配合媒体服务器反代时：

```yaml
services:
  MyPan:
    image: desstg/mypan:latest
    container_name: MyPan
    restart: unless-stopped
    network_mode: host        # 用了 host 网络就不要写 ports:
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - /vol1/1000/docker/MyPan/data:/app/data
      - /vol1/1000/docker/MyPan/strm:/app/strm
      - /vol1/1000/docker/MyPan/mounts:/app/mounts:shared
    devices:
      - /dev/fuse:/dev/fuse
    pid: "host"
    privileged: true
```

host 网络下端口直接监听在宿主机上，`5211` 和 `42069` 都自动可用。

### 方式三：docker run

```bash
docker run -d \
  --name MyPan \
  --restart unless-stopped \
  --pid host \
  --privileged \
  --device /dev/fuse \
  -p 5211:5211 \
  -p 42069:42069/tcp \
  -p 42069:42069/udp \
  -e TZ=Asia/Shanghai \
  -v /volume1/docker/MyPan/data:/app/data \
  -v /volume1/docker/MyPan/strm:/app/strm \
  -v /volume1/docker/MyPan/mounts:/app/mounts:shared \
  desstg/mypan:latest
```

加 `--network host` 的话去掉所有 `-p`。

### 首次启动

1. 打开 `http://你的IP:5211`
2. 用默认账号 **`admin` / `admin`** 登录
3. **系统会强制你先改密码** —— 在改掉默认密码之前，后台其他页面都是锁定的，只会显示一个「导入备份」的卡片。这是**正常行为，不是出错了**。
4. 改完密码后，进入「存储管理」添加你的第一个网盘账号
5. 建议紧接着去「仪表盘 → 系统日志」确认没有报错

> **忘记密码怎么办**：登录页有「忘记密码」，点击后系统会生成一个**临时密码并打印到容器日志里**，10 分钟内有效。执行 `docker logs MyPan` 查看。
>
> 临时密码同样会触发强制改密。

### 目录说明

| 宿主机目录 | 容器内路径 | 作用 |
|---|---|---|
| `./data` | `/app/data` | SQLite 数据库、全部配置、日志、密钥文件 |
| `./strm` | `/app/strm` | STRM 文件输出位置 |
| `./mounts` | `/app/mounts` | FUSE 挂载点目录（**必须 `:shared`**） |
| `./fuse_read_cache` | `/app/data/fuse_read_cache` | 可选，FUSE 读缓存，建议放 SSD |

**`data` 目录是全部身家**，备份它等于备份了整个 MyPan。注意复制时要把 `MyPan.db-wal` 和 `MyPan.db-shm` 一起复制，否则可能丢最近的数据。

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `MyPan_DATA_DIR` | `./data` | 数据目录 |
| `MyPan_STRM_DIR` | `./strm` | STRM 输出目录 |
| `MyPan_DB_PATH` | `<数据目录>/MyPan.db` | 单独指定数据库路径 |
| `MyPan_LISTEN` | `:5211` | HTTP 监听地址 |
| `MyPan_LOG_LEVEL` | `info` | 日志级别 |
| `MyPan_SECRET_KEY` | 自动生成 | 会话签名、STRM 签名、备份加密的主密钥。不设的话会自动生成到 `data/secret.key` |
| `MyPan_CORS_ORIGINS` | 空 | 额外允许的跨域来源，逗号/分号/换行分隔 |
| `MyPan_MOUNT_ROOT` | `/app/mounts` | FUSE 挂载根目录 |

**绝大多数配置都在网页后台里改，不需要碰环境变量。** 上面这些是给特殊部署场景用的。

> ⚠️ **TMDB 不是用环境变量配的。** 网上流传的 `TMDB_API_BASE_URL` 环境变量在这个版本里**不存在**。TMDB 的 API Key、语言、API 域名、图片域名在网页后台「任务管理 → 目录整理 → 设置」里填；代理是全局的，在「系统设置 → 其他设置 → 网络代理」里填。

### 网络：TMDB 访问不了怎么办

刮削和目录整理都依赖 TMDB。如果服务器连不上 `api.themoviedb.org`，有三个办法，**任选其一**：

**办法一**：在「系统设置 → 其他设置 → 网络代理」里配一个全局代理。TMDB 和 TG 频道抓取共用这一份。

**办法二**：在「目录整理 → 设置」里填 TMDB 反代域名（会自动补 `/3` 和 `/t/p`）。

**办法三**：给容器加 hosts。Compose 写 `extra_hosts`，docker run 用 `--add-host`：

```yaml
    extra_hosts:
      - "api.themoviedb.org:对应的IP"
      - "image.tmdb.org:对应的IP"
```

### 端口说明

| 端口 | 协议 | 用途 |
|---|---|---|
| `5211` | TCP | 网页界面和 API |
| `42069` | TCP + UDP | 内置磁力下载的 BT 监听端口（TCP/uTP + DHT） |

用不到内置磁力下载的话，`42069` 可以不映射。**但如果要映射，TCP 和 UDP 必须都给**，只给 TCP 会导致 DHT 找不到节点、下载极慢。

### 群晖 / 飞牛注意事项

- 群晖的 **Container Manager 图形界面**不能完全覆盖这里的配置（尤其是 `privileged` 和 `pid: host`），建议用 SSH 跑 `docker compose`，配置文件放在 `/volume1/docker/MyPan`。
- 群晖的 Docker **没有 buildx 组件**。如果你要自己构建镜像而不是拉现成的，注意源码里的 Dockerfile 已经适配了这一点（不能用 `RUN --mount=type=cache` 这类 BuildKit 专属语法）。
- 飞牛用 `/vol1/1000/` 作为数据根路径，其它一样。

## 三、已知限制

- **没有公开分享链接功能。** 「文件共享」页面实际提供的是 WebDAV 和 FUSE 挂载，是给自己用的，不能生成一个链接发给别人下载。
- **秒传不是通用能力**，只在部分网盘作为目标时生效，详见[能力表](#1-多网盘聚合)。
- **夸克不支持 302 直链**，只能走本机代理，播放会走服务器带宽。
- **`.doc` / `.ppt` / `.rar` / `.7z` 不能在线预览**，需要下载后用本地程序打开。压缩包只支持 zip / cbz。
- **FUSE 是编译期开关**（`-tags fuse`）。官方镜像已经打开；如果你自己从源码编译，忘了加这个 tag 会得到「未编译 FUSE 支持」的报错。
- **AI 整理和分类整理默认关闭**，需要在设置里手动开启并配置（AI 默认接 DeepSeek 兼容接口）。

## 四、常见问题

**登录进去只看到一个「导入备份」的卡片，别的页面都点不动？**
正常，你在用默认密码。先改密码，其他页面就会解锁。

**打开首页就跳登录页，不能免登录浏览？**
默认如此。「系统设置 → 账号安全」里有「允许匿名访问文件列表」开关，打开后不登录也能看文件列表。

**FUSE 挂载失败？**
依次检查四件事：宿主机 `/dev/fuse` 是否存在、容器是不是 `privileged: true`、`pid` 是不是 `"host"`、`mounts` 卷有没有写 `:shared`。这四项缺任何一个都会挂不上，绝大多数情况是漏了 `:shared`。

**Emby 里 STRM 播放不了？**
先确认 STRM 里的播放地址能被 Emby 所在机器访问到，再检查「系统设置」里的 STRM 基础地址是不是填的内网地址。如果网盘直链域名变了，用「播放地址替换」工具批量更新已有 STRM。

**刮削一直失败 / 目录整理匹配不上？**
基本都是 TMDB 网络问题，参见[上面的网络章节](#网络tmdb-访问不了怎么办)。

**磁力下载没速度？**
先确认 `42069` 的 **TCP 和 UDP 都映射了**。这是 DHT 节点发现的前提，只映射 TCP 会非常慢。

**容器日志在哪？**
`./data/log` 目录下按天分文件。也可以在网页「仪表盘 → 系统日志」里看。注意镜像是 `scratch` 基础、**没有 shell**，`docker exec` 进不去，排障请用日志。
